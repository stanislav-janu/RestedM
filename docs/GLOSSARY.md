# Glossary

Every word RestedM puts on screen. One name per idea, in buttons, menus, tooltips and messages.

| Term | Means | Not |
| --- | --- | --- |
| Request | One `.request` document: method, URL, headers, parameters, body and options | call, query, endpoint |
| Response | What the server sent back: status, headers and body | result, reply |
| Method | The HTTP method of a request (GET, POST, …) | verb, type |
| URL | The address a request goes to, as typed, with `{{name}}` placeholders | link, endpoint, address |
| Resolved URL | The URL after placeholders and query parameters are filled in, exactly as sent | final URL, real URL |
| Header | One name and value sent with a request or received with a response | field, meta |
| Parameter | One name and value filled into the URL, query string or body | param, argument, field |
| HTTP Body | Raw text sent instead of the parameters ("Use Custom HTTP Body") | payload, content, data |
| Send Request | Send the request and show its response (⌘R) | run, execute, fire |
| Stop Request | Cancel a request that is still waiting for its response (⌘R) | abort, cancel request |
| Authorization | The Basic username and password of a request | auth, login, credentials |
| Text Encoding | The character set used for the URL, parameters and body (UTF-8, ISO Latin-1, ASCII) | encoding, charset |
| Form-encoded, JSON-encoded | How parameters are written into the body | format, content type |
| Follow Redirects | Follow 3xx responses to their new location | redirect, auto-redirect |
| Sent Request | The request exactly as it went out, shown in the response pane | Request tab, raw request |
| Status | The response's code and reason, such as "404 Not Found" | result, code |
| Response Time | Time from sending to the last byte of the response | duration, latency |
| Environment | A named set of variables, such as dev, staging or prod | profile, workspace, context |
| Variable | One name and value in an environment, used as `{{name}}` | constant, key |
| History | The list of requests sent from this Mac, newest first | log, recents |
